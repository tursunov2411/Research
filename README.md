# Uzbekistan's Economic Integration with Northeast Asia: Trade, FDI, and GVCs

This repository contains the complete research pipeline, empirical data, compilation scripts, and final academic outputs for the dissertation investigating Uzbekistan's integration into Northeast Asian (China, Japan, South Korea) Global Value Chains (GVCs) following the 2017 liberalisation reforms.

## 📌 Project Overview
The research empirically demonstrates a central structural asymmetry in Uzbekistan's industrialisation: significant backward GVC integration (importing intermediate goods) without commensurate forward integration (manufacturing exports), signifying a "captive" governance structure. The project is compliant with the **Tashkent State University of Economics (TSUE)** BMI requirements and features an extensive empirical pipeline spanning World Bank, UNCTAD, and Observatory of Economic Complexity (OEC) data.

## 📂 Repository Structure & Workflow

### 1. Data Ingestion & Processing
The research leverages programmatic data collection via R and Python to ensure reproducibility:
- **`fetch_trade_data.R`**: Pulls macroeconomic indicators (WDI), FDI flows, and bilateral trade data (OEC BACI). 
- **`data/raw/`**: Contains the raw, unmanipulated datasets from APIs.
- **`data/processed/`**: Cleaned panel datasets used for regressions and visualizations (e.g., `uzbekistan_panel.csv`, `eci_data.csv`).

### 2. Empirical Analysis & Robustness
The quantitative core of the thesis relies on time-series OLS regressions, structural break testing, and network analysis:
- **`empirical_checks.R`**: Computes VIF (multicollinearity), Breusch-Pagan (heteroskedasticity), and Durbin-Watson (autocorrelation) tests.
- **`network_analysis.R` & `network_analysis.qmd`**: Generates directed trade network graphs mapping Uzbekistan's dependency on Northeast Asian nodes.
- **`generate_figures.R`**: Creates all publication-quality ggplot2 visualizations.
- **`output/tables/`**: LaTeX tables (generated via Stargazer) representing regression models and empirical robustness checks.
- **`figures/`**: Directory containing all finalized charts, heatmaps, and network visualisations.

### 3. Literature Saturation
- **`fetch_literature.py`**: Interacts with the OpenAlex API to dynamically fetch 300+ highly relevant, peer-reviewed articles matching specific GVC and FDI themes.
- **`references_expanded.bib`**: The master BibTeX database storing all curated references.

### 4. Thesis Compilation (TSUE Compliant)
The dissertation source code is entirely LaTeX-based, managed through custom Python build scripts to guarantee institutional formatting compliance:
- **`build_tsue.py`**: A master Python script that integrates the thesis chapters, enforces TSUE formatting (14pt Times New Roman, 1.5 spacing, specific heading structures), and systematically injects 150-250 real citations contextually into the literature review.
- **`chapters/`**: Contains the isolated LaTeX source files for each chapter (e.g., Literature Review, Methodology, Analysis).
- **`report_tsue.tex`**: The main TSUE-compliant LaTeX document generated by the build script.
- **`compile_report.ps1`**: A PowerShell script automating the `pdflatex -> bibtex -> pdflatex` compilation sequence.

### 5. Applied Policy Toolkit
Derived from the academic thesis, this repository also contains a standalone, decision-oriented toolkit for policymakers and IPAs:
- **`policy_toolkit/`**: Contains applied outputs including a GVC Readiness Scorecard, Sector Targeting Matrix, Policy Trigger Framework, and Navoiy Air-Cargo Policy Brief.
- **`policy_toolkit/policy_toolkit_main.tex`**: Source code for the toolkit report.

## 📄 Final Deliverables
By running the compilation scripts, the pipeline generates the following finalized documents:
1. **`report_tsue.pdf`**: The official, defense-ready PDF thesis.
2. **`dissertation_tsue_compliant.docx`**: The supervisor-ready Word Document, generated natively via Quarto Pandoc.
3. **`policy_toolkit/policy_toolkit_main.pdf`**: The professional applied policy briefing.

## 🚀 How to Replicate
1. Run data scripts: `Rscript fetch_trade_data.R` and `Rscript empirical_checks.R`
2. Fetch literature: `python fetch_literature.py`
3. Build the compliant thesis: `python build_tsue.py`
4. Compile PDF: Execute `.\compile_report.ps1`
5. Generate Word Document: `quarto pandoc report_tsue.tex -o dissertation_tsue_compliant.docx`
