# Uzbekistan Thesis Project

Open this project in R/RStudio from:

```text
C:/Users/nuobe/Desktop/Apps/Contoller OS/uzbekistan_thesis
```

The correct RStudio project file is:

```text
uzbekistan_thesis.Rproj
```

All scripts assume the working directory is the `uzbekistan_thesis`
project root. In R, check with:

```r
getwd()
```

It should end with:

```text
uzbekistan_thesis
```

If it shows the parent folder `Contoller OS`, open
`uzbekistan_thesis.Rproj` directly or run:

```r
setwd("C:/Users/nuobe/Desktop/Apps/Contoller OS/uzbekistan_thesis")
```
